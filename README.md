# 🌐 HTML & CSS Practice

A collection of HTML, CSS, Bootstrap, responsive-layout, and frontend practice exercises from earlier web-development learning.

## 📚 Topics Covered

- Semantic HTML
- Forms and input elements
- CSS box model
- Flexbox and Grid
- Positioning and display
- Media queries and responsive layouts
- Bootstrap components and grids
- Navigation bars
- Animations
- Basic frontend page recreations

## 📂 Examples

The repository contains standalone practice pages such as:

- `BOOTSTRAP.html`
- `bootstrapgrid.html`
- `flexbox.html`
- `grid.html`
- `mediaQueries.html`
- `navbar.html`
- `animation.html`
- `Ecommers.html`
- `instagramClone.html`
- `netflix.html`

These are learning exercises rather than production applications. Current portfolio projects are maintained in separate repositories.
